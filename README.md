# hometrix/homebrew-tap

Official Homebrew Tap for **Splash Monitor** and Apple Silicon tools by [JMGREP Developers](https://github.com/hometrix) (Joan Gregorio Pérez).

## 🌊 Splash Monitor

Native macOS status bar monitor and visual management app for [Inco AI Splash](https://github.com/incoai/splash) local inference engine on Apple Silicon.

### Install via Homebrew

```bash
brew install --cask hometrix/tap/splash-monitor
```

Or tap first and install:

```bash
brew tap hometrix/tap
brew install --cask splash-monitor
```

### Upgrade

```bash
brew upgrade splash-monitor
```

### Uninstall

```bash
brew uninstall --cask splash-monitor
```
